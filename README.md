# Homework Journal

This project is set up so you can keep a simple personal journal for class and share it with your professor.

## How to update it

1. Open the site in the browser.
2. Click New entry.
3. Add a title, date, type, notes, and tags.
4. Click Save entry.
5. Click Export journal.
6. Save the downloaded file and replace the project version of entries.json.
7. Commit and push the repo.

## What your professor sees

When the site is published with GitHub Pages, the professor can open the site and read your updated entries from the homepage.

## Simple rule

The easiest workflow is:

- Add notes in the browser
- Export the updated data
- Commit the updated file to GitHub

That keeps the journal personal to you and easy to review.
